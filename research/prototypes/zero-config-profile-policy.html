Throwaway logic prototype

Detect the project. Do not invent confidence.

This demo tests the zero-config policy behind bare siloscan. It makes project setup visible, runs the checks Siloscan already proves, saves one report, and refuses to activate ecosystem rules that have never passed a noise and performance corpus.

Decision: a valid manifest explains the project. It does not activate new finding rules by itself. Launch stays on the measured 220-rule secret pack until each ecosystem add-on earns admission with reproducible evidence.

Recommended launch contract

Ship project detection. Ship no unmeasured ecosystem profile.

A Cargo manifest proves that a repository uses Cargo. It says nothing about the false positive rate of a proposed Rust rule. Bare v2 should therefore add truthful project metadata, capability reasons, durable JSON, and same-command review while keeping the current finding baseline intact.

  1. 1The existing default pack stays whole and keeps all 220 secret rules.
  2. 2Line, code-line, and duplication metrics still run once over the admitted inventory.
  3. 3Text, syntax, boundary, coverage, and duplication findings run only when effective rules and required inputs select them.
  4. 4The existing pack is labeled default-secrets@1. Every ecosystem add-on reports none at launch because no versioned measured add-on exists.
  5. 5Later profiles activate only on the automatic journey after their own corpus and the 5% gates pass.

Bare human scan

            
Print Project, Scope, Setup, Languages, Checks, Profiles, and Findings. Keep current finding, ignored, filtered, and metrics lines. After a successful save, print Report: <path> then Review: siloscan review.

          

          

            
JSON or SARIF stdout

            
Write one parseable document and nothing else. JSON carries additive setup metadata. SARIF stays unchanged. After successful publication, stderr receives Report: <path> then Review: siloscan review.

          

          

            
Explicit compatibility

            
Detection metadata may be recorded, but no detected profile changes findings. Existing output stays exact. A requested save adds only the settled report and review notices.

          

          

            
Publication failure

            
Emit the completed scan result, print one save error to stderr, omit Report and Review success lines, and exit 2. A preflight failure emits no scan output.

          

          

            
No saved report

            
--no-save and stateless explicit scans print no Report or Review lines. Review never guesses a temporary or another scope.

          

          

            
No runnable rules

            
If embedded defaults are disabled and no other rule source remains, preserve the current no-rules refusal. Do not scan, save, or print a clean result.

          

        

      

    


    

      

        

          

            
Profile admission gate

            
A profile ships after evidence, not enthusiasm.

          

          

            These conditions apply to each fixed embedded profile. Passing one ecosystem does not
            authorize another.
          

        


        

          
01
Version it
Use globally unique rule IDs and a fixed embedded profile version. No downloaded rules, plugin registry, or mutable remote source.

          
02
Name the trigger
Activate from accepted evidence facts and admitted language files. A manifest name alone is not enough when its contents are invalid or executable.

          
03
Measure noise
Commit positive fixtures and a pinned negative corpus. Every expected finding must appear, every classified negative must stay quiet, and measured recall must be recorded as a floor.

          
04
Keep compatibility
Explicit PATH and existing v1 option journeys retain admitted files, findings, fingerprints, baselines, metrics, machine output, and status.

          
05
Pass performance
Compare explicit v1.5.1 and v2 scans in --no-cache, cold, and warm states; bare v1.5.1 and v2 --no-save in cold and warm states; and bare v1.5.1 and v2 automatic save in cold-first-publication and warm-replacement states. Measure wall time and OS peak RSS independently for every path and state with nine paired ABBA samples on one GitHub Actions runner. A ratio above 1.05 is suspected; repeat the complete pair on a fresh runner and block the same path, state, and metric when it exceeds 1.05 twice. Invalidate a reference series above 20% median absolute deviation and retain raw samples.

          
06
Stay additive
A profile may add findings. It cannot disable the default pack, lower severity, filter scan scope, invent architecture, or require a project tool or network. Its rules load once and must self-scope by language or exact path.
